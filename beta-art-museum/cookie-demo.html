Cookie Banner

A GDPR-compliant cookie banner in the BETA ART design language. This page shows it working, explains what it does, and gives you the code to paste into every HTML page.

§ 01Live preview

Click the buttons below to interact with the banner. State is saved to localStorage and displayed underneath so you can see what the visitor's browser stores.

§ 02Two categories, no dark patterns

GDPR forbids pre-checked boxes and requires equally easy Accept and Reject. This banner uses only two categories — necessary (always on) and analytics (opt-in). No advertising cookies. No third-party trackers. No fingerprinting.

Category A · Necessary
Always active

Required for the site to function. Cart state, language preference, session security. Legal basis: legitimate interest (GDPR Art. 6.1.f). Cannot be turned off.

betaart:cart:v1
betaart:lang:v1
betaart:consent:v1
Category B · Analytics
Opt-in only

Privacy-friendly analytics via Plausible (no cookies, no fingerprinting, EU-hosted). Used only to understand page traffic. Legal basis: consent (GDPR Art. 6.1.a).

No cookies set.
Plausible.io script loaded
only after consent.

§ 03Integration — three steps per page

Paste three snippets into every HTML page: the CSS, the HTML markup, and the JavaScript. The banner uses the same localStorage LANG_KEY as your other pages, so language switches everywhere at once.

Step 1 — CSS (inside <style> or in your stylesheet)

Copy the block marked BETA ART COOKIE BANNER — start / end from this file's <style> block. About 60 lines.

Step 2 — HTML (just before </body>)

<!-- BETA ART COOKIE BANNER — HTML -->
<div id="ba-cookie" role="dialog" aria-live="polite" aria-label="Cookie consent">
  <div class="ba-c-inner">
    <div class="ba-c-eyebrow" data-i18n="cookie.eyebrow">Cookies</div>
    <div class="ba-c-title" data-i18n="cookie.title">A quick word about cookies</div>
    <div class="ba-c-body" data-i18n-html="cookie.body">
      This site uses only what's necessary to function — cart state,
      language preference. If you accept analytics, we also load
      Plausible, a privacy-friendly analytics tool. No advertising
      cookies. Ever. See our <a href="/privacy.html">privacy policy</a>.
    </div>
    <div class="ba-c-actions">
      <button class="primary" onclick="baCookieDecision('all')" data-i18n="cookie.acceptAll">Accept all</button>
      <button onclick="baCookieDecision('necessary')" data-i18n="cookie.necessary">Necessary only</button>
    </div>
  </div>
</div>

Step 3 — JavaScript (before your existing <script>)

// BETA ART COOKIE BANNER — JavaScript
const BA_COOKIE_KEY = "betaart:consent:v1";
const BA_PLAUSIBLE_DOMAIN = "betaart.no"; // change to your domain

function baCookieState(){
  try { return JSON.parse(localStorage.getItem(BA_COOKIE_KEY)); }
  catch(e) { return null; }
}
function baCookieDecision(kind){
  const state = {
    necessary: true,
    analytics: kind === "all",
    ts: new Date().toISOString(),
    v: 1
  };
  try { localStorage.setItem(BA_COOKIE_KEY, JSON.stringify(state)); } catch(e){}
  document.getElementById("ba-cookie").classList.remove("show");
  if (state.analytics) baLoadPlausible();
}
function baCookieShow(){ document.getElementById("ba-cookie").classList.add("show"); }
function baCookieReset(){
  try { localStorage.removeItem(BA_COOKIE_KEY); } catch(e){}
  baCookieShow();
}
function baLoadPlausible(){
  if (document.getElementById("ba-plausible")) return;
  const s = document.createElement("script");
  s.id = "ba-plausible";
  s.defer = true;
  s.src = "https://plausible.io/js/script.js";
  s.setAttribute("data-domain", BA_PLAUSIBLE_DOMAIN);
  document.head.appendChild(s);
}
// On page load: decide whether to show banner or load analytics
(function(){
  const state = baCookieState();
  if (!state) baCookieShow();
  else if (state.analytics) baLoadPlausible();
})();

Bonus — Footer link to reopen banner

Users must be able to change their mind. Add this button anywhere in your footer:

<button class="ba-cookie-open" onclick="baCookieReset()">
  <!-- EN -->Manage cookies
  <!-- NO -->Håndter informasjonskapsler
</button>

§ 04Integration checklist

Apply to every page that visitors can land on directly. That means all six existing pages, plus any future ones.

  • ☐ index.html (main site — beta-art-v3.html)
  • ☐ privacy.html
  • ☐ license-terms.html
  • ☐ faq.html
  • ☐ contact.html
  • ☐ qr.html (already noindex; still recommended)

  • ☐ Change BA_PLAUSIBLE_DOMAIN to your real domain
